
# To-Do List Manager

## About
A console-based To-Do List Manager developed using C++.
It helps users organize and manage their daily tasks.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Display pending and completed status

## Concepts Used
- C++ functions
- Arrays
- Loops
- Conditional statements
- Switch statements
- Strings
- Boolean variables

## How to Run
1. Compile using: g++ main.cpp -o todo
2. Run using: ./todo

## Language
C++
